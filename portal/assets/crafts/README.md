# Craft app artwork

Unmodified 256 × 256 Linux hicolor PNG exports from the pinned Craft forks.
They are displayed at 48–72 CSS pixels, covering up to 3× pixel density without
upscaling. No runtime dependency on editor checkouts or external image hosts.

The app icons are MIT OR Apache-2.0. These copies are redistributed under MIT;
the original copyright and permission notices are included in `licenses/`.
Additional icon-specific notices are retained where provided by upstream.
The ArtCraft umbrella trademark/logo is not included.

PhotoCraft, PdfCraft and FigCraft use the project owner’s original engraved
creature artwork. WordCraft, DeckCraft, SoundCraft, CADCraft and GridCraft use
the original artwork supplied by their respective project contributors; several
are described upstream as temporary icons awaiting mascot illustrations.
